# LIILO – E-Commerce Product Showcase

## Project Overview

LIILO is a modern online fashion store website designed to showcase stylish and modest clothing and accessories.

The website provides users with a simple and visually appealing shopping experience where they can explore different fashion categories, view products, review a static shopping cart, and learn more about the LIILO brand.

This project was created as part of my Software Engineering learning journey to practice HTML5, CSS3, responsive design, Git, and GitHub.

---

## Features

The LIILO website includes:

- Responsive navigation bar
- Hero section with a call-to-action
- Featured products section
- Product collection with different categories
- Product cards with images, prices, ratings, and buttons
- Category and sorting controls
- Static shopping cart page
- Order summary
- About LIILO page
- Contact page with a contact form
- Hover effects and CSS transitions
- Responsive design
- Accessible image alt text
- Consistent typography and color scheme
- CSS-only dark mode
- Mobile-responsive layouts

---

## Product Categories

## Dark Mode

LIILO includes a CSS-only dark mode structure.

The dark mode does not use JavaScript. Instead, CSS can detect whether the user's device or browser is using a dark color scheme.

The dark mode is created using the CSS:

```css
@media (prefers-color-scheme: dark) {
    /* Dark mode styles */
}
